# Font sources

Bundled Latin WOFF2 subsets: Lora (normal / italic), IBM Plex Sans (normal), served by Google Fonts. Chinese uses the reader's system fonts. Fonts are embedded in the generated HTML; no requests are made to Google Fonts when reading.

- [Lora source and OFL](https://github.com/google/fonts/tree/main/ofl/lora)
- [IBM Plex Sans source and OFL](https://github.com/google/fonts/tree/main/ofl/ibmplexsans)

The two adjacent OFL license files apply to these fonts. They are separate from the repository content license. Font binaries are unmodified; original subset filenames are retained.

Generated single-file readers include both copyright notices and license texts in an expandable footer.
